# yt-dlp-wrapper
Script wrapper en .bat de yt-dlp pour un téléchargement et une conversion facile de vidéos youtube en mp3

## Installation

1. Télécharger l'exécutable de [yt-dlp](https://github.com/yt-dlp/yt-dlp)
2. Le ranger dans le dossier exec
3. Télécharger [ffmpeg]https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases 
4. Le déplacer sous exec\ffmpeg\bin ou indiquer son path dans le code source si déjà installé

## Utilisation

```bash
.\yt-dlp-wrapper.bat
```
ou double clic sur le fichier .bat.
